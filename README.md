# Implementaciones de FIFO y LIFO en C

Este repositorio contiene implementaciones básicas en lenguaje C de dos estructuras de datos fundamentales:
1. **FIFO** (*First In, First Out* - Cola / Queue)
2. **LIFO** (*Last In, First Out* - Pila / Stack)

---

## 🚀 Compilación y Ejecución

Puedes compilar y ejecutar cada programa desde la terminal con los siguientes comandos:

### Para FIFO (Cola):
```bash
gcc fifo.c -o fifo
./fifo

## Para LIFO (Pila):
```bash
gcc lifo.c -o lifo
./lifo
